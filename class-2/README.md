# Class 2 · Sensors and smart systems

[School roadmap](../README.md)

This is the DHT22/TB6612FNG part of [Optional Hardware Variations](../resources/hardware-variations.md). Use this kit’s matching wiring and sketches. The main DHT11/L298N class starts at [Read inputs and make decisions](../student-course/03-inputs-light-and-climate.md).

Use the circuits from Class 1 to build systems that read inputs and make decisions. By the end, you will be able to calibrate a sensor, explain PWM, power a motor through a driver, and integrate the subsystems into one bench project.

## Lessons

1. [Digital and analog I/O](01-digital-analog-io/README.md)
2. [PWM LED dimmer](02-pwm-dimmer/README.md)
3. [LDR voltage divider and night light](03-ldr-night-light/README.md)
4. [DHT22 temperature and humidity alarm](04-dht-alarm/README.md)
5. [Ultrasonic distance and proximity buzzer](05-ultrasonic-proximity/README.md)
6. [Brushed DC motor and TB6612FNG driver](06-dc-motor-driver/README.md)
7. [Smart home bench project](07-smart-home/README.md)

## Before moving on

Demonstrate the smart home acceptance checks. Record safe motor power connections, your threshold measurements, and how your build behaves when a sensor fails.
