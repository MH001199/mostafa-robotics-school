# Glossary

[Start Learning](../student-course/README.md) · [Components](components.md)

| Term | Meaning in this course |
| --- | --- |
| ADC | Analog-to-digital converter. The Uno reports an input level from 0 to 1023 with its default 10-bit setting. |
| Actuator | A part that changes the physical world, such as a motor. |
| Baud rate | Serial signalling rate. Choose the same setting in the sketch and monitor. |
| Breadboard node | Holes joined by the same metal contact. A node can connect multiple leads. |
| Duty cycle | Fraction of one PWM period spent HIGH. |
| Firmware | Software running on an embedded controller. |
| GPIO | General-purpose input/output pins configured for a signal direction. |
| GND | Ground reference shared by the signals in a circuit. |
| H-bridge | Circuit that controls voltage polarity across a motor. |
| Hysteresis | Separate on and off thresholds that reduce rapid toggling near one value. |
| Pull-up | Resistor that gives a signal a defined HIGH while it is otherwise undriven. |
| PWM | Rapid digital switching whose on-time can vary. |
| Sketch | Arduino source program, stored in a matching folder with an `.ino` file. |
| Stall current | Current a motor can draw when voltage is applied and the shaft cannot turn. Use the specified rating. |
| Timeout | Limit on waiting for a signal that might never arrive. |
