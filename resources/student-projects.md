# Student Projects

[Start Learning](../student-course/README.md) · [Class 3 Roadmap](../class-3/README.md)

Publish your work in your own GitHub repository or fork. Include the problem, parts list with model numbers, wiring diagram, sketch, expected behavior, and observations. Label tests as compiled, simulated, or physically tested. Add a short note about one thing you tried that did not work and what it taught you.

Once Discussions is enabled, share a link under **Student Project Showcase**. Use a pull request to this curriculum when you have a specific improvement to a lesson, diagram, sketch, or test. Avoid posting personal information in public photos, logs, or screenshots.

## Practice GitHub first

[GitHub Skills](https://skills.github.com/) offers practice with commits, pull requests, and reviews. For a first contribution, reproduce one lesson and report a verifiable improvement. See the [contribution guide](../CONTRIBUTING.md).
