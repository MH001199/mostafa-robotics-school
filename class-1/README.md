# Class 1 · Arduino fundamentals

[School roadmap](../README.md)

Start with a bare Uno. By the end, you will be able to upload a sketch, wire a current-limited LED, sequence several outputs, and play an original piezo melody.

## Lessons

1. [Arduino, IDE and Blink](01-arduino-and-blink/README.md)
2. [Breadboard LED](02-breadboard-led/README.md)
3. [Traffic light model](03-traffic-lights/README.md)
4. [Passive piezo buzzer](04-piezo-buzzer/README.md)
5. [Compose a melody with AI](05-ai-melody/README.md)

## Before moving on

Build the traffic light from the diagram without borrowing a friend's wiring. Explain why each LED needs a resistor. Upload your edited melody and show how one note’s duration appears in code.
