# Code of Conduct

Welcome beginners, explain assumptions, and discuss evidence respectfully. Focus feedback on the work. Harassment, discriminatory language, personal attacks, spam, and publishing another person’s private information are unacceptable.

For an urgent safety correction, open a concise wiring issue with the board and affected lesson. For conduct concerns, contact a repository maintainer privately through an available GitHub profile contact method. Use GitHub’s reporting tools if private contact is unavailable or the issue involves platform abuse. Avoid posting sensitive details publicly.

Maintainers may remove harmful content, restrict participation, or report abuse. They should consider the severity, context, and impact and preserve privacy when following up.
