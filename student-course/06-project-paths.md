# Choose a project after Class 3

[Course map](README.md) · [Previous: Smart-home capstone](05-smart-home.md)

This is the planned theory bridge and project menu from the full course. The [shared Class 3 roadmap](../class-3/README.md) lists the prerequisite skills.

Class 3 is the point where students stop relying on isolated starter projects and learn how robotics subsystems work together. Content should be added later as real experiments are completed and documented.

- Motor families: brushed DC, hobby servo, stepper, and brushless DC; torque/speed/control differences; appropriate drivers (H-bridge, servo signal/PWM controller, stepper driver, ESC).

- Communication protocols: UART (point-to-point serial), I2C (shared-address bus), SPI (clocked, high-throughput device interface), and module pinout decisions.

- Advanced sensors: gyroscopes and IMUs, more accurate environmental sensors, encoders, GPS, etc.; choosing measurement range, noise and sample rate.

- System-level examples: robotic arm kinematics, remote-control rover, drone components and power safety, self-balancing robots with feedback/PID.

- Student project branches: Bluetooth RC car, 4-servo joystick robotic arm, self-balancing robot, autonomous ROS2 rover, IoT monitoring, and future projects released with tested documentation.

Prerequisites to every branch: Complete Class 1 + Class 2 + essential Class 3 theory. Students then select a project path. No untested "ready-to-run" code is promised here.
