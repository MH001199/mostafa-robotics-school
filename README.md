# Mostafa's Robotics School

A beginner path into robotics and embedded systems. Start with a single LED, build a controller that can sense and act, then use those skills to choose a project track.

**[Start Learning](student-course/README.md).** Follow the Class 1 and 2 projects in order, from getting the Uno ready to the smart-home capstone. This route uses the DHT11 and L298N from the course handbook.

Start with [Section 00 · Foundations](Class-01-Arduino-Fundamentals/00-Introduction/README.md), then follow the core DHT11/L298N learning path. [Image sources](IMAGE-SOURCES.md)

## Follow the core course

| Stage | What you will do |
| --- | --- |
| [Section 00](Class-01-Arduino-Fundamentals/00-Introduction/README.md) | Identify the Uno and breadboard, then upload a serial connection test |
| [Class 1](student-course/02-leds-and-sound.md) | Build light and sound outputs |
| [Class 2](student-course/03-inputs-light-and-climate.md) | Read sensors, control a motor, and build the smart-home capstone |
| [Class 3 foundations](class-3/README.md) | Choose a specialization after the planned theory bridge |

The core uses the **Uno R3, DHT11, L298N, LDR and HC-SR04**. If you have a DHT22 and TB6612FNG, use the [Optional Hardware Variations](resources/hardware-variations.md) and their matching sketches.

## Share a build

For a wiring fix, open a GitHub issue with your lesson, board, wiring, and the observed result. For a curriculum improvement or a reproducible student project, submit a pull request with a purpose, parts list, pin map, sketch, expected behavior, test results, and any hardware limits. Include a clear photo or diagram when it helps somebody repeat the build.

See [sketch verification](VALIDATION.md) for build commands and the scope of testing.
